# Estudos 2FA – TOTP

Repositório criado para documentar meus estudos sobre autenticação em duas etapas (2FA), com foco na implementação de TOTP (Time-Based One-Time Password).

O objetivo é registrar os conceitos estudados, as decisões técnicas e as etapas de desenvolvimento de uma possível implementação de 2FA.

### Estrutura

- **docs/** – Documentação e anotações referentes a cada etapa do estudo.
- **totp-poc/** – Prova de conceito (POC) utilizando TOTP, com implementação do serviço e testes automatizados.

### Objetivo

Consolidar o conhecimento sobre autenticação em duas etapas, segurança, gerenciamento de sessões temporárias e validação de códigos TOTP, mantendo os exemplos práticos e a documentação organizados em um único lugar.
